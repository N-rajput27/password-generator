# Password Generator

A simple web-based password generator built using HTML, CSS, and JavaScript.

## About the Project

This project was created to practice frontend web development and JavaScript.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Use the password generator interface.

## Project Structure

- `index.html` — Web page structure
- `style.css` — Styling and layout
- `script.js` — JavaScript functionality

## Learning Goals

- Practice JavaScript fundamentals
- Work with HTML and CSS
- Build an interactive web page
